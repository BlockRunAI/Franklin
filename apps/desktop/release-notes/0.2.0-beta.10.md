# Franklin Desktop 0.2.0-beta.10

- Paste a screenshot with Cmd+V / Ctrl+V, preview or remove it, and send it to the model, including an image-only message. Images chosen with the file picker now reach the model too.
- Copy buttons on generated code and tables write to the system clipboard again, and only show "Copied" once the copy succeeded.
- The model dropdown lists each provider's newest models first.
- Includes the agent question, Skills and Auto model improvements from beta.8 and beta.9.

Available for macOS Apple Silicon and Windows x64. These beta installers are unsigned. Install this version to receive the fixes; automatic in-app updates remain unavailable.
