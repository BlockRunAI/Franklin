Franklin Desktop beta for macOS Apple Silicon and Windows x64.

## What's improved

- **Import and manage real Skills.** Skills now has an Add skill control for pasting or choosing a SKILL.md. Imports reach the local agent registry; list, enable/disable, refresh and removal work against that registry. Use in chat prepares an explicit slash command without sending it. New imports and toggles take effect on the next message without restarting the session.
- **Open-source API Skills are compatible.** Standard YAML frontmatter, nested metadata, multiline descriptions and curl examples are accepted. Public OpenClaw weather is covered as an unmodified compatibility fixture. Commands preserve the user's request even when a Skill omits `$ARGUMENTS`.
- **Requirements stay explicit.** Importing a Skill saves its instructions; it does not install software, include supporting files, grant API credentials or bypass tool approvals. Referenced supporting files are flagged. Duplicate names and malformed files produce visible errors, and built-in/project Skills cannot be deleted through the import manager.
- **Dedicated Trading Mode.** Enable Settings → Trading Mode for a focused chart and conversation workspace. Creative model catalogs, gallery, marketplace and project/agent navigation are hidden until you exit. Chat history, wallet and settings stay available.
- **Public spot markets alongside chat.** BTC/USD and ETH/USD use public Kraken data, with six candle intervals, volume, live/freshness states, a candle table and dated market references added to your draft. Viewing or referencing data never places an order.
- **Calmer interaction and compact type.** A warm charcoal/amber palette, smooth pane transitions, consistent chat/composer alignment and scrollable settings menus address sudden jumps, oversized text and narrow-window layout issues. Reduced motion is respected.
- **Current local runtime.** Native development resolves this checkout's runtime; packaged builds use their embedded runtime and retain its version metadata.

## Downloads

- `Franklin-0.2.0-beta.4-arm64.dmg` — Apple Silicon Macs
- `Franklin.Setup.0.2.0-beta.4.exe` — Windows x64
- `SHA256SUMS.txt` — download verification

The installers are unsigned beta builds. The macOS build is not notarized; Windows is not code-signed. OS first-run protections may require user confirmation. This release does not include Linux or Intel Mac installers.

Skill import/readiness was tested without paid inference or trading. Import compatibility does not guarantee that every third-party Skill's tools, credentials or supporting files are available in your environment.
