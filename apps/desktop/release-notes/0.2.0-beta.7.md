# Franklin Desktop 0.2.0-beta.7

- Keep the Skills list responsive while recursive file searches are running, and allow searches to be cancelled.
- Add Auto to the chat model picker, using Franklin’s existing automatic model routing.

Available for macOS Apple Silicon and Windows x64. These beta installers are unsigned. Install this version to receive the fixes; automatic in-app updates remain unavailable.
