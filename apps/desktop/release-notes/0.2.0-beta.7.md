# Franklin Desktop 0.2.0-beta.7

- **Updates in the sidebar.** A newer Desktop release adds Update Franklin to
  the left sidebar. Download inside the app, then choose Restart to update.
  The compact action remains available with a collapsed sidebar or Trading Mode.
- **Native installation.** Supported updates use Squirrel.Mac on signed macOS
  builds and a silent NSIS upgrade on Windows, then relaunch Franklin. Active
  chat, media and Team tasks block the restart. Updates are not installed merely
  by quitting after a download.
- **Verified update payloads.** Desktop releases are selected separately from
  CLI releases. Update metadata, hashes, file sizes and signatures are checked;
  failed checks and interrupted transfers can be retried from Settings.

Beta.6 and earlier did not contain an updater. Install this version manually
once to receive future in-app updates. Legacy releases without update metadata
use the explicit installer flow.

macOS release publishing requires Developer ID signing and Apple notarization.
Unsigned branch CI builds are for testing and cannot demonstrate signed macOS
replacement. Windows builds currently use the existing unsigned beta installer.
